## 🖼️ Solution Architecture Diagram

The following diagram illustrates the complete Retail Sales Analytics Platform.

Data flows from source CSV files into Informatica Intelligent Cloud Services (IICS), where staging, dimension processing, fact loading, and data quality validations are performed. The curated data is stored in SQL Server Data Warehouse and consumed through interactive Power BI dashboards for business reporting and analytics.
